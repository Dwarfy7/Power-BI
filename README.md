# Power BI — Northwind BI Homework

## Overview

This project was completed as part of my data analysis studies. It uses Microsoft Power BI to practice business intelligence, data visualization, and report development using the Northwind dataset.

## Project Objectives

The project involved exploring business data and presenting information through Power BI reports and visualizations, following the assignment requirements.

## Tools & Technologies

- **Power BI Desktop** — report development and visualization
- **DAX** — calculations and measures, where used
- **Data modeling** — organizing data for reporting, where applicable

## Project Files

- **Power BI report (`.pbix`)** — the report created for the assignment.
- **Supporting data files** — related materials used in the project.

## How to View the Project

Download the `.pbix` file and open it in Power BI Desktop to explore the report.

## What I Learned

This assignment helped me practice using Power BI to explore business data, create visualizations, and present information in a report format.
